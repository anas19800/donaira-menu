# دونيرا — نظام إدارة المنيو 🍽️

نظام بسيط لإدارة منيو المطعم وعرضه أونلاين وتوليد نسخة PDF للطباعة مع رمز QR.

## رابط المنيو للزبائن (أونلاين)

**https://anas19800.github.io/donaira-menu/**

هذا هو الرابط الذي يفتحه الزبائن ويشير إليه رمز الـ QR. يتحدث عند الضغط على زر **"🚀 نشر أونلاين"** في صفحة الإدارة (يستغرق التحديث دقيقة تقريباً).

## التشغيل على جهازك (الإدارة)

```bash
npm install
npm start
```

ثم افتح المتصفح على:

| الصفحة | الرابط |
|---|---|
| الإدارة | http://localhost:3000/admin |
| المنيو أونلاين | http://localhost:3000/menu |
| نسخة الطباعة و PDF | http://localhost:3000/print |

## المزايا

- **الإدارة**: أقسام وأصناف (اسم عربي/إنجليزي، سعر + سعر ثانٍ اختياري مثل لحم/دجاج، وصف، سعرات حرارية، صورة بالرابط أو بالرفع، ترتيب بالأسهم، إظهار/إخفاء).
- **الاستيراد**: من CSV أو Excel — الأعمدة المطلوبة: `القسم، اسم المنتج، السعر` واختيارياً: الاسم الانجليزي، السعر 2، الوصف، السعرات، رابط الصورة، ظاهر. وضعان: دمج أو استبدال كامل.
- **التصدير**: CSV أو Excel بكل الأعمدة (يصلح لإعادة الاستيراد).
- **المنيو أونلاين**: تصميم متجاوب RTL بدون سلة مشتريات، مع تبديل عربي/إنجليزي.
- **QR**: من زر QR في الإدارة — يشير لرابط المنيو (يمكن تحديد رابط خارجي من الإعدادات) مع تحميل PNG.
- **الطباعة**: قالب مطابق للتصميم المطبوع (أعمدة، شرائط الأقسام، شارات الأسعار والسعرات، QR). خيارات: ورق A4/A3، عدد الأعمدة، إظهار/إخفاء الصور/الإنجليزي/الوصف/السعرات، حجم الخط مع **احتواء تلقائي**، واختيار الأصناف الظاهرة في المطبوعة صنفاً صنفاً.
- **القوالب**: احفظ عدة قوالب (كل قالب يتذكر خياراته والأصناف المختارة) وبدّل بينها ثم اضغط "توليد PDF".

## البيانات

تُحفظ في `data/db.json` (نسخة احتياطية = نسخ هذا الملف). الصور المرفوعة في `data/uploads/`، وكاش الصور الخارجية في `data/imgcache/`.

عند أول تشغيل بدون قاعدة بيانات، يستورد النظام `seed_menu.csv` تلقائياً.
